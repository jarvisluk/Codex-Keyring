# Codex Keyring 小红书封面整理包

这个文件夹整理了本会话生成的 Codex Keyring 小红书封面与安全素材。

## 推荐使用

- `final/01-recommended-native-screenshot-cover.png`
  - 当前推荐版本。
  - 使用真实 App 界面展示，账号信息已做遮挡。
  - 1080 x 1440，适合小红书竖版封面。

## 文件夹说明

- `final/`
  - 最终候选图与较完整的备选方向。
- `variants/`
  - 过程中生成的封面风格版本，方便回看和挑选。
- `carousel/`
  - 可作为小红书多图笔记的界面展示页。
- `assets/`
  - 已处理过的安全素材，包括 icon cutout、遮挡后的 App 窗口、菜单截图。
- `debug/`
  - 对比图、contact sheet、抠图检查图，仅供回溯制作过程。

## 隐私说明

原始未遮挡窗口截图没有放入这个整理包。包内截图素材均为遮挡或处理后的版本。
